
# Senai_LLP_File_Brasileirao

## Descrição
Aplicação em Java que lê um arquivo de texto com resultados de partidas 
de futebol, processa a pontuação de cada time e exibe a tabela de 
classificação final do campeonato.

## Funcionalidades
- Leitura de arquivo `jogos.Txt` linha por linha
- Processamento de vitória (3pts), empate (1pt) e derrota (0pts)
- Cálculo de saldo de gols (gols feitos - gols sofridos)
- Ordenação decrescente por pontos, com desempate por saldo de gols
- Exibição formatada da tabela de classificação

## Como executar
1. Clone o repositório
2. Abra no IntelliJ IDEA
3. Certifique-se que o `jogos.Txt` está na pasta `src/`
4. Execute a classe `Main`

## Tecnologias
- Java 25
- IntelliJ IDEA
